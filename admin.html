Publish Changes to Website

Commit live updates to your GitHub Pages hosting repository

Push your latest treatments, articles, doctors, hero slides, and page banners directly to your GitHub repository. Once committed, GitHub Pages will automatically rebuild and deploy your changes worldwide in ~30 to 60 seconds.

Example: kmunshidk/nallayil-website
Stored securely in this browser's localStorage only. Never shared or sent to any third party.
How to generate a free GitHub Token (1 minute guide)
  1. Go to github.com and click your profile icon (top right) → Settings.
  2. Scroll down to the bottom of the left sidebar → click Developer Settings.
  3. Click Personal access tokens → Tokens (classic).
  4. Click Generate new token (classic). Note: Nallayil Admin.
  5. Check the repo scope box (Full control of private/public repositories).
  6. Click Generate token at the bottom, copy the token (starts with ghp_), and paste it above!

Download Updated data.js File

If you do not want to use a GitHub Token, download this single file and upload it to your GitHub repository.

How to update on GitHub (10 Seconds):

  1. Open your repository on github.com in your browser.
  2. Navigate into the js/ (or site/js/) folder.
  3. Click the Add file button (top right) → choose Upload files.
  4. Drag & drop the downloaded data.js file into the browser window.
  5. Scroll down and click the green Commit changes button.
  6. All done! GitHub Pages will deploy automatically, and all visitors will see the updated content.

This saves all changes to this browser's localStorage. It is useful for testing and previewing changes on your own device before publishing to GitHub. Note that other visitors will NOT see these changes until you commit to GitHub.
